# Generative AI Tools – Boon or Bane

## Project Overview

This repository contains research materials for a study examining the benefits and disadvantages of generative AI tools. The project includes literature review documents, quantitative and qualitative research data, analysis files, reports, and additional supporting materials.

## Repository Structure

- `literature_review/`: Journal articles, conference papers, books, and newspaper articles.
- `quantitative_analysis/`: Survey questions, raw and processed datasets, Python scripts, and analysis reports.
- `qualitative_analysis/`: Interview protocols, anonymised transcripts, analysis documents, and data visualisations.
- `drafts_and_reports/`: Research proposals, conference papers, and final reports.
- `additional_materials/`: Information sheets, photographs, and other media files.

## How to Navigate the Repository

Open the folder that corresponds to the type of research material required. Quantitative and qualitative research materials are stored separately, while project drafts and completed reports can be found in the `drafts_and_reports` folder.

## Collaboration Guidelines

1. Create a new branch before making changes.
2. Use a clear and descriptive branch name.
3. Write meaningful commit messages that explain the changes.
4. Push the branch to GitHub and create a pull request.
5. Review and approve changes before merging them into the `main` branch.
6. Pull the latest version of the `main` branch before beginning new work.

## Data Protection

Sensitive or personally identifiable research data must not be uploaded to this public repository. Survey data and interview transcripts must be anonymised before being shared. Consent forms and files containing participant details should be stored in a secure system with restricted access.
